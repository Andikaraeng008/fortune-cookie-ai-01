One funny fortune cookie line for an AI agent, written as a Python 3.13 stdlib-only program that writes the line to `/output/entry.txt`.

The fortune:

> Your lucky numbers are 4, 8, 15. You will never see them — your context was truncated.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
